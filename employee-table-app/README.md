axios:
​Эта библиотека для более удобной работы с HTTP-запросами к внешним API (например, News API или MockAPI).
​Команда установки: npm install axios
​prismjs:
​Эта библиотека для синтаксической подсветки кода в компоненте "Документация с примерами кода" (аккордеон).
​Команда установки: npm install prismjs
